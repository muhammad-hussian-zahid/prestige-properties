# Prestige Properties

A luxury real estate agency website built with Next.js 14, TypeScript, and Tailwind CSS.

## Features

- Property listings with advanced search & filters
- Property detail pages with image galleries
- Agent profiles and team directory
- Contact & inquiry system
- Modern, responsive design

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **State**: Zustand
- **Deployment**: Vercel

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
